# 《绝顶》多玩法方案 v1

> 目标：在现有「论招」（骗子酒馆牌类玩法）之外扩展 2–3 种玩法，共用房间、角色、
> 演出与联机骨架。
>
> **状态（v1.0 已全部落地）**：心魔 / 暗器 / 递毒三模式已实现并上线，开场与等待厅均可自选玩法。
> 三模式技能层暂关（按 §6 对策），玩顺后逐个开。

---

## 1. 筛选标准（不满足任何一条即出局）

1. **读人是核心乐趣**——和本作的魂一致：信息不对称 + 诈唬 + 出招用时可见
2. **内核可复用**——回合制、状态小、能塞进现有 DO 房间与事件管道
3. **美术可复用**——六侠立绘/表情/石板/牌桌全保留，新增资产 ≤ 10 张图
4. **2–4 人、一局 5–15 分钟**——匹配现有房间与判定标准
5. **规则一页纸**——教学成本 ≤ 现有模式

## 3. 入选详案

### 模式 A ·「心魔」——现有论招局的房间开关（工程量：~1 天）

> 原型：骗子酒馆"扑克地狱"恶魔牌。已在候选池挂了很久，这次落地。

**规则增量**（其余照旧）：
- 牌堆 20 张中换入 **1 张心魔牌**（替换 1 张化劲 → 6/6/6/1/1）
- 心魔**只能单张打出**，且**永远算真牌**
- 若下家拆招掀出的是心魔 → **除出牌者外，全场各退一步**

**博弈点**：握着心魔的人巴不得被拆；全场都要记"心魔还没现身"。
中后期"他单张出牌"会变成最恐怖的信号。

**落地**：房间开关（默认关）＋牌面 1 张（PixelLab：狰狞面具/心魔妖影）。
内核改动 ≈ 30 行，双端各一份；新增边界 4 条（单张限制/必真/群体退步/金钟罩交互）。

---

### 模式 B ·「暗器」——大话骰的武侠壳（工程量：~4 天）

> 原型：骗子酒馆骰子模式 / Perudo（大话骰）。原作两大模式之一，不做等于只抄了半个原作。

**规则**（一页纸）：
1. 每人一只**暗器囊**，内藏 **5 枚暗器**，种类随机（六种：飞刀/柳叶镖/毒针/铁蒺藜/袖箭/**无影针**＝百搭）
2. 只有自己看得见囊中之物
3. 轮流**叫价**："全场至少有 N 枚 X"——每次叫价必须**加码**（N 更大，或 N 相同兵器更稀有）
4. 轮到你时二选一：**加码**，或对上家喝一声"**拆招！**"
5. 拆招后全场亮囊清点：叫价成立 → 拆招者退一步；不成立 → 上家退一步
6. 每退一步，下一局你的暗器囊**少一枚**（信息越来越少，越输越依赖读人）
7. 石板轮盘照旧：退到虚石坠崖，最后站着的赢

**为什么值得做**：与论招的乐趣剖面完全不同——论招是"我在骗你"，暗器是**全场共谋一个越吹越大的牛皮，看谁先绷不住**。数学控和读人派都有得玩。

**复用**：石板/坠崖/技能（金钟罩听劲辨虚实语义微调）/表情/等待厅全复用。
**新增资产**：6 枚暗器图标（32px）+ 暗器囊 + 掷出动画 1 条 ≈ 8 次生成额度。
**内核**：新文件 `game_dice`（GDScript + JS 双端），事件管道与房间协议不动，房间加 `mode` 字段。

### 模式 C ·「递毒」——蟑螂扑克的武侠壳（工程量：~4 天）

> 原型：Cockroach Poker。诈唬桌游公认的教科书；它的"传递声明"结构和我们"一对一读人"完美互补。

**武侠壳先声夺人：五毒教篇。** 毒物就是**五毒**：蛇、蝎、蜈蚣、蟾蜍、蜘蛛——比蟑螂老鼠体面一万倍的本土化。

**规则**（一页纸）：
1. 牌堆：五毒各 8 张（共 40 张，2–4 人通用），全部发完
2. 出手人从手中**盖一张**递给任意一人，声称："**这是蝎。**"（可以撒谎）
3. 收礼人三选一：
   - **"信了"**——掀开。说对了 → 出手人吃下这张；说错了 → 自己吃下
   - **"不信"**——掀开。说错了 → 出手人吃；真说对了 → 自己吃
   - **"转赠"**——自己偷看一眼，**换个声称**盖着递给第三人（只剩两人可选时不能再转）
4. 吃下的毒摆在面前，**全场可见**
5. **同一种毒集满 4 只 → 毒发出局**；场上只剩一人未毒发 → 胜
6. 手牌打空的人不再出手，但仍会被递毒

**为什么值得做**：它是唯一"指名道姓一对一"的玩法——递给谁本身就是宣战。
桌面状态全公开（谁快集齐蝎了全场都知道），围剿与反围剿的社交烈度是三个模式里最高的。

**复用**：立绘/表情/等待厅全复用；不用石板（毒物计数就是血条）。
**新增资产**：五毒牌面 5 张 + 毒盒牌背 1 张 + 毒发演出 1 条 ≈ 10 次生成额度。
**内核**：新文件 `game_poison`，注意新机密类型——"转赠者偷看过的牌"只进当事人视图。

## 4. 共享架构（三个模式共用的改动，先行一步）

```
房间(DO) ──选模式──▶ 内核工厂: mode ∈ { 论招 | 暗器 | 递毒 }
                       │ 统一接口: newGame / apply / viewFor / legalActions / events
等待厅 ─────────────▶ 石匾下加一行模式选择（房主定，全员可见）
结算/表情/角色/重连 ─▶ 零改动，天然共用
```

- 事件类型按模式命名空间化（`DICE_*` / `POISON_*`），UI 演出层按模式挂子场景
- 每模式独立的判定数据（局时长/超时率），互不污染

## 5. 路线图（每步都过"热座→联机→真人局"三关）

| 站 | 内容 | 预估 |

| v1.0 | 模式 A 心魔开关 + 共享架构（mode 字段贯通） | 1–2 天 |

**顺序理由**：A 最便宜且直接给现有模式续命；B 是原作另一半，玩家预期内；
C 差异最大，放最后压轴。**每一站结束都是可发布状态**，不搞三线并行。

## 6. 风险与对策

- **模式分流**：2–4 人本来就少，模式多了更凑不齐 → 等待厅默认"论招"，其他模式做成房主的选项而非并列入口
- **技能系统跨模式失衡**：暗器/递毒下六技能语义要逐个重审 → 各模式先带"技能：关"上线，玩顺了再逐个开
- **恶魔牌方差**（模式 A）：一张牌炸全场，方差极大 → 默认关，写明"派对开关"
