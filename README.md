# 绝顶

> 华山之巅，群雄论招。诈与被诈，一步之间。

## 🎮 立即游玩

**[▶ 点这里直接玩（浏览器打开即玩，无需安装）](https://99yyy.github.io/card-game/)**

联机方法：输入名号 → 创建联机房 → 把石匾上的六位房号发给朋友 → 朋友输房号加入（2–4 人，人不够可补机器人）。

---

一款武侠题材的多人诈唬卡牌游戏，**内置四种玩法**，开场即选、联机房主可切换。

## 四种玩法

| 玩法 | 一句话 |
|---|---|
| **论招** | 经典诈唬：每轮定路数（刀/剑/掌），盖牌虚报、拆招定生死；六块石板一块虚，退到虚石坠崖。叠加「盘外招」技能层（自选可重复、全场公开） |
| **心魔** | 论招变体：牌堆混入一张心魔——只能单出、永远为真，**谁拆它，除出牌者外全场连坐退步** |
| **暗器** | 大话骰武侠壳：暗器囊藏 5 枚（含百搭无影针），轮流叫价加码"全场至少 N 枚 X"，拆穿开囊清点；**越输囊里越少** |
| **递毒** | 五毒蟑螂扑克：盖盒递毒声称种类，收家信/不信/**偷看后转赠祸水**；同种集满 4 只毒发出局 |

六位侠士皮囊自由选（待机呼吸、专属表情、坠崖挣扎均为逐帧动画），
手机横屏可玩，2–4 人，机器人可填位。

## 目录

| 路径 | 内容 |
|---|---|
| `core/` | 游戏内核 ×3（论招+心魔 / 暗器 / 递毒，纯逻辑无 UI，边界规则全测试覆盖） |
| `ui/` | Godot 客户端（单机热座版：1 真人 + 3 机器人） |
| `server/` | Cloudflare Worker + Durable Object 联机服务（JS 内核移植版） |
| `tests/` | 内核测试套件（`--headless` 运行） |
| `assets/` | 像素美术（PixelLab 生成） |
| `docs/` | 规则草案（唯一规则权威）、实现规格 |

## 本地运行（单机版）

需要 [Godot 4.7](https://godotengine.org/)：

```bash
godot --path .
```

跑测试：

```bash
godot --headless --path . --script res://tests/run_tests.gd
```

## 联机服务端

```bash
cd server
node --test test/        # 内核测试
npx wrangler dev --local # 本地起服
npx wrangler deploy      # 部署 Cloudflare
```
